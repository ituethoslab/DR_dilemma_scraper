# Dilemma Scraper

This is a simple and quick scraping tool to scrape the dilemmas found in the [Sara ^ Monopolet - podcast](https://www.dr.dk/lyd/p4/sara-og-monopolet-podcast-1090358387000) DR page.

It's hard coded to extract dilemmas, for a more general scraping template you can request access to the code by emailing me.

All requirements are in the `pyproject.toml` file.

As the tool is made to be used once, it is not maintained. The to-do list below can also be seen as the main missing features of the tool.
